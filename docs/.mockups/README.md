# Mockups: extension-first setup

Approved sketches for the install and setup flow. They show flow and wording, not final polish. Each PNG has the HTML it was rendered from.

- `journey.png`: twelve frames following a new user from the Chrome Web Store to their first agent answer. Start here.
- `setup-flow.png`: the four screens to build.
  - A: app not found, with the detected platform as the top row.
  - B: app found but not set up; setup inside the extension.
  - C: "Settings" in the toolbar icon's context menu.
  - D: the Settings view in the side panel.
- `install-flow.png`: an earlier sketch of the platform picker and the install method per platform. Superseded by `setup-flow.png` where they differ: the detected platform is always first.

Known flaws in the sketches:

- Platform icons are placeholder letters.
- `agentmark.sh/install`, version numbers and the extension ID are placeholders.
- Chrome's permission dialog wording is from memory and not checked against a real build.
