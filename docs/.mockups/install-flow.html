2. Pick a platform: one command

‹ All platforms

Install on Mac, Apple Silicon

1

Open Terminal and paste this:

curl -sSL https://raw.githubusercontent.com/codesoda/agentmark/main/install.sh | bash -s -- --extension-id kdfhgpjmlecnoaipbhkolgbmaeidcjdnCopy

It downloads the app and connects it to this extension. Nothing else to type.
